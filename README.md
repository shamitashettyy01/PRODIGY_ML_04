# Hand Gesture Recognition using Machine Learning

## 📌 Overview
This project is a part of my Data Science Internship at Prodigy InfoTech.  
The goal of this project is to develop a hand gesture recognition model that can classify different hand gestures from image data.

---

## 🎯 Objective
To build a machine learning model capable of recognizing and classifying various hand gestures.

---

## 📂 Dataset
The dataset contains images of different hand gestures such as:
- Palm
- Fist
- Victory
- Thumbs Up

---

## 🛠️ Technologies Used
- Python
- NumPy
- PIL
- Scikit-learn
- Jupyter Notebook

---

## ⚙️ Steps Performed
1. Imported required libraries  
2. Loaded gesture image dataset  
3. Resized and preprocessed images  
4. Converted images into arrays  
5. Trained the classification model  
6. Predicted hand gestures  
7. Evaluated model performance  

---

## 📊 Model Used
- Support Vector Machine (SVM)

---

## 📈 Outcome
Successfully developed a hand gesture recognition model capable of identifying different gestures from images.
